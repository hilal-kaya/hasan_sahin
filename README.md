# Doç. Dr. Hasan Şahin — kişisel web sitesi

Siyah ağırlıklı, mobil uyumlu Türkçe kişisel web sitesi. Yayınlanabilir dosyalar `dist/` klasöründedir; derleme veya paket kurulumu gerektirmez.

Yerel önizleme: `python3 -m http.server 4173 --directory dist`

## İçerik kaynakları

- https://www.docdrhasansahin.com/
- https://sayfam.btu.edu.tr/h.sahin
- https://bukagem.btu.edu.tr/
- https://scholar.google.com/citations?user=3MqbElMAAAAJ&hl=tr

Ünvanlar ve araştırma alanları bu sayfalardaki bilgilere dayanır. Yeni ürün, proje, akademik metrik veya başarı iddiası eklenmemiştir. Araştırma alanlarının açıklamaları, bu alanları ziyaretçiye tanıtan genel metinlerdir.

## Fotoğraflar

Mentorun kullanıcı tarafından yeniden tasarlanması istenen mevcut sitesindeki fotoğraflar kullanılmıştır. Açık lisans iddiası bulunmaz. Orijinallerden web için boyutlandırılmış WebP kopyaları üretilmiştir; siyah-beyaz görünüm CSS ile uygulanır.

MÜSİAD Bursa fotoğrafı belirli bir BUKAGEM etkinliği olarak tanımlanmamıştır. Google Fonts bağlantısının erişilememesi durumunda sistem yazı tipleri kullanılır. İletişim bağlantıları ziyaretçinin e-posta uygulamasını açar; site mesaj kaydetmez veya otomatik göndermez.
